Ordinary host page

This static page runs on a separate origin so the widget’s host cookie, iframe isolation, responsive sizing, and page-context updates can be tested exactly as they will be on a customer site.

Start MarshalDesk, then serve this directory separately with npx serve demo -l 3333. Copy the actual snippet from the dashboard, paste it below, and install it.

Host controls remain independent
